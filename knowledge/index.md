# Conocimiento del Observatorio

Catálogo de colecciones de conocimiento del Observatorio, preparado para lectura humana y consumo progresivo por agentes y herramientas de inteligencia artificial.

## Colecciones

* [Encuesta Bienal de Culturas](./ebc/) - Formularios, preguntas, variables y documentación de la Encuesta Bienal de Culturas.

## Cómo usar este catálogo

1. Lea este índice para identificar la colección pertinente.
2. Siga el enlace al índice de la colección.
3. Consulte primero el documento conceptual Markdown para conocer el alcance, la estructura y las restricciones del recurso.
4. Acceda al archivo JSON enlazado desde el campo `resource` únicamente cuando necesite procesar los registros.

Los archivos `index.json` se conservan como manifiestos auxiliares para aplicaciones. La navegación OKF canónica comienza en este archivo.
